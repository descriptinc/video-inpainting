Inpainting fills a masked region of a video with new content that matches everything around it. The rest of the frame stays untouched, and the fill holds steady for the full length of the video. Long videos are possible because of Anchored Tree Sampling.

Examples

Each clip plays its Original, then the Masked region to regenerate, then the Inpainted result. Use the toggle to step between them.

Method

Inpainting regenerates a masked region and leaves the rest of the frame untouched. A pretrained video-to-video generator fills the region so it moves with the scene around it. The hard part is doing that consistently for minutes at a time.

Anchored Tree Sampling

The model generates a few seconds at a time, so long videos are usually built by autoregressive rollout: each chunk is conditioned on the one before it. Errors compound, and the fill slowly drifts. Surrounded on every side by footage that never changes, that drift is easy to see.

ATS fills the timeline sparse to dense instead. A root call places anchor frames across the whole video, guidance calls add anchors between them, and leaf calls fill each span between neighboring anchors. Every call after the root is bracketed by anchors on both sides, so drift stays bounded no matter how long the video is. Calls on the same level are independent and run in parallel.

The tree that unlocks long generation

Goodbye Drift: Anchored Tree Sampling for Long-Horizon Video-to-Video Generation

A training-free scheduler for any two-sided video-to-video generator. The paper shows stable 40+ minute generations across five conditioning modalities, inpainting included, and a 5.3× speedup over the strongest autoregressive baseline at a 2000 s horizon.
